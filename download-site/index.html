DIASCO

Assistant Android avec dictée vocale, caméra, code, images et création de sites.

Télécharger l’APK Android Voir le tutoriel

Version 2.4.4 - Android 6.0 et plus

Installation

  1. Touchez le bouton de téléchargement depuis votre téléphone Android.
  2. Ouvrez le fichier APK téléchargé.
  3. Autorisez l'installation depuis le navigateur si Android le demande.
  4. Lancez DIASCO. Le mode en ligne est déjà configuré.

Important

Cette version est distribuée hors Play Store. Android peut afficher un avertissement normal avant l'installation. Cette version utilise le backend HTTPS DIASCO déjà configuré. Les utilisateurs n’ont aucune URL à saisir.

Les clés des fournisseurs IA ne sont pas dans l'application. Elles restent uniquement côté serveur.
